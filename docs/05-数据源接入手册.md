# 05 · 数据源接入手册

在「新增数据源」弹窗中，**最少只需填三项**：平台、链接(Base URL)、凭证。其余字段均可留空或按需填写。

---

## 一、ShowDoc

- **链接**：ShowDoc 站点地址，如 `https://doc.example.com`
- **凭证（任选其一）**：
  - `{"api_key":"...","api_token":"..."}` （开放 API 页面获取）
  - `api_key:api_token`
  - `cookie: xxx=yyy; zzz=www` （无开放 API 权限时的降级方案）
- **高级选项**：
  - `itemId`：只同步指定项目
  - `endpoints.itemList / pageList / pageInfo`：覆盖默认接口路径（适配自部署版本差异）
- 抓取链路：项目列表 → 目录/页面列表 → 页面正文（Markdown）。

## 二、GitHub

- **链接**：`https://api.github.com`（GitHub.com）或自部署 GHE（如 `https://ghe.example.com/api/v3`）
- **凭证**：Personal Access Token（裸串，如 `ghp_xxx` / `github_pat_xxx`），建议仅授予只读权限
- **高级选项**：
  - `repos`：`owner/repo,owner/repo2`（留空自动发现可访问仓库）
  - `owner` / `org`：限定用户或组织
  - `branch`：指定分支（默认仓库默认分支）
  - `include` / `exclude`：文件路径正则（默认 `.md/.mdx/.markdown/.rst/.txt`）
  - `maxFilesPerRepo`：单仓库最多文件数（默认 200）
- 支持 YAML front matter（`title`/`tags` 自动提取）。

## 三、Gitee

- **链接**：`https://gitee.com/api/v5`
- **凭证**：私人令牌 Access Token（裸串）
- **高级选项**：同 GitHub（字段一致）。

## 四、禅道（ZenTao）

- **链接**：禅道站点地址，如 `https://zentao.example.com`
- **凭证**：`{"account":"admin","password":"xxx"}` 或 `admin:password`
- **高级选项**：
  - `authMode`：`v1`（默认，禅道 18+）/ `token`（直接持有 token）/ `legacy`（老版本 session 接口）
  - `modules`：`product,story,task,bug,doc`（默认全同步）
  - `productId`：只同步指定产品
- 抓取：产品 → 需求(story)/Bug(bug)，执行 → 任务(task)，以及文档(doc)。

## 五、印象笔记 / Evernote

- **默认走 ENEX 导出（最稳、零依赖）**：
  - **高级选项**：`enexPath` = 本地 `.enex` 文件、目录、或可访问的 URL
  - 在印象笔记中「导出为 ENEX」，把文件放到某目录即可一次性并入。
- **可选 Cloud API 模式**：
  - `mode=api`，需安装可选依赖 `npm i evernote`
  - 凭证：`{"devToken":"S=..."}` 或裸串 token
- 笔记标题、正文、标签、笔记本层级都会被保留。

## 六、腾讯文档

- **本地导出模式（默认，零依赖）**：
  - 在腾讯文档「更多 → 导出为」选择 Word/Excel/Markdown → 落到本地目录
  - **高级选项**：`mode=local`、`dir=<导出目录>`
  - 自动解析 `.docx` / `.xlsx` / `.md` / `.txt` / `.html` / `.enex`
- **开放平台 API 模式**：
  - `mode=openapi`，凭证 `{"access_token":"..."}`
  - 默认端点 `/openapi/v2/files` 与 `/openapi/v2/files/{id}/content`，可通过 `endpoints` 覆盖

## 七、MCP 服务器（客户端接入）

见 [`docs/04-MCP接入说明.md`](04-MCP接入说明.md)。

## 八、本地目录 / 文件

- 平台选「本地文件 / 目录」，**高级选项** `dir` 填目录或单文件路径（也支持 http(s) 直链）。
- 支持：Markdown / 文本 / HTML / CSV / ENEX / Word / Excel。

## 九、通用 OpenAPI / HTTP（兜底）

对任意提供 JSON 列表接口的系统，用字段映射接入：

```json
{
  "listPath": "/api/v1/documents",
  "listRoot": "data.items",
  "itemMapping": { "id": "id", "title": "name", "content": "body", "url": "url" },
  "contentPath": "/api/v1/documents/{id}",
  "authHeader": "bearer",
  "pagination": { "type": "page", "param": "page", "size": 100, "maxPages": 10 }
}
```

## 凭证写法速查

| 平台 | 写法 |
|---|---|
| ShowDoc | `{"api_key":"..","api_token":".."}` |
| GitHub | 裸 PAT 串 |
| Gitee | 裸 token 串 |
| 禅道 | `{"account":"..","password":".."}` |
| 印象笔记 | 默认无需凭证（ENEX）；API 模式 `{"devToken":".."}` |
| 腾讯文档 | 默认无需凭证（导出目录）；API 模式 `{"access_token":".."}` |
| 通用 | 对方 API Token |
