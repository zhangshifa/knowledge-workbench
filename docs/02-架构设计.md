## 三、统一文档模型（UnifiedDoc）

所有平台的内容最终归一化为同一结构，这是"知识与经验统一"的地基。

```js
{
  id:            "sha1(sourceId + externalId)", // 全局唯一
  sourceId:      "src_xxx",        // 所属数据源
  platform:      "github",         // showdoc|github|gitee|zentao|evernote|tencent-docs|mcp|local|generic
  externalId:    "owner/repo:path",
  title:         "部署指南",
  path:          "docs/deploy.md", // 平台内的层级路径
  type:          "doc",            // doc|page|note|bug|task|story|sheet|experience
  url:           "https://...",    // 回跳原文
  summary:       "前 200 字纯文本摘要",
  content:       "# 部署指南\n...", // 正文（Markdown 优先）
  plainText:     "部署指南 ...",    // 去标记纯文本（用于检索与摘要）
  tags:          ["部署", "docker"],
  author:        "zhangshifa",
  createdAt:     "2026-08-01T00:00:00Z",
  updatedAt:     "2026-08-20T00:00:00Z",
  meta:          { /* 平台特有字段，原样保留 */ },
  indexedAt:     "2026-08-29T12:00:00Z"
}
```

**设计取舍**
- `meta` 保留平台原生字段，避免"归一化即丢信息"。
- `id` 由 `sourceId + externalId` 哈希得出，保证重复同步幂等。
- `plainText` 与 `content` 同时保留：检索用前者，阅读用后者。

## 四、检索设计

- **分词**：中文按 bigram（二字滑窗）切分，英文/数字按 `[a-z0-9]+` 词元切分，统一小写。
- **索引**：`token -> {docId: termFreq}` 倒排表，落盘 `data/index.json`。
- **打分**：BM25（k1=1.5, b=0.75），标题字段权重 ×2，标签命中额外加权。
- **高亮**：返回命中 token 在 `plainText` 中的窗口片段。
- **规模**：万级文档全内存索引，启动即载入；更大场景可替换为外部引擎（见"演进路线"）。

## 五、同步模型

```
sync(source):
  1. decrypt(credential)
  2. connector.fetchAll({ baseUrl, credential, options, since })
       → 逐页拉取，产出 UnifiedDoc[]
  3. store.upsertDocs(sourceId, docs)   // 幂等 upsert
  4. store.pruneRemoved(sourceId, externalIds) // 源端已删除的，本地标记归档
  5. search.reindex(sourceId)
  6. record sync history { startedAt, finishedAt, count, status, error }
```

- 支持 `since` 增量：若连接器返回 `updatedAt`，且与本地一致则跳过正文拉取。
- 失败重试：指数退避，最多 3 次；单次同步错误不影响其他源。
- 定时：`syncIntervalMinutes`（默认 120，0 表示仅手动）。

## 六、凭证安全

- 落盘：`AES-256-GCM`，密钥 = `scrypt(KB_MASTER_KEY, salt)`，密文含 `iv + tag + ciphertext`，Base64 存储。
- 环境变量：`KB_MASTER_KEY` 未设置时，使用数据目录下的随机密钥文件（权限 600），并在首次启动时提示。
- 传输：建议 HTTPS；`KB_API_TOKEN` 启用后所有 `/api/*` 需 `Authorization: Bearer`。
- 回显：所有 API 返回的凭证字段一律以 `***` 掩码。
- 日志脱敏：URL 中的 `token=`、`access_token=` 等参数自动打码。

## 七、三端实现策略

三端**共享同一套前端代码与同一套后端 API**，差异只在宿主：

| 端 | 宿主 | 差异点 |
|---|---|---|
| Web | 浏览器 | 侧边栏常驻 + 三栏布局 |
| 移动 | 浏览器 / PWA | 媒体查询切换为单栏抽屉式；Service Worker 缓存静态资源与最近文档 |
| 桌面 | Electron | 主进程拉起本地服务 → `BrowserWindow` 加载 `127.0.0.1:PORT` |

这样保证"一次开发、三端可用"，也保证功能不会在不同端之间漂移。
